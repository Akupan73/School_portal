# School Portal (UI)

This is a scaffolded Vite + React + MUI project that provides a small school portal UI with Dashboard, Login, and Registration (tabs).

Quick start

```bash
cd school-portal
npm install
npm run dev
```

Full-stack run (frontend + backend)

1. Start backend API:

```bash
cd school-portal/server
npm install
npm start
```

2. Start frontend (from project root):

```bash
cd school-portal
npm install
npm run dev
```

By default the frontend will call the backend at `http://localhost:4000`. You can change the base URL by creating a `.env` file in `school-portal` with `VITE_API_URL`.

Files created: `src`, `src/pages`, `src/components`, `index.html`, `vite.config.js`, `package.json`.
